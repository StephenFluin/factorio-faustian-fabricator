# Factorio Faustian Fabricator Mod

## Project Context
This is a Factorio mod for Factorio 2.0 and 2.1. It features a "Faustian Fabricator" that levels up and generates items over time.

## Supporting 2.0 and 2.1
- Factorio only loads mods whose `factorio_version` matches the game's major.minor, so `python3 build_mod.py` builds one archive per version into `dist/2.0/` and `dist/2.1/`, overriding `factorio_version` in each. The repo's `info.json` stays on 2.1 for local testing.
- `data.lua` checks `mods["base"]` to use `category` (2.0) or `categories` (2.1) on recipes. `control.lua` uses `defines.inventory.crafter_output`, which exists in both.

## Graphics
Entity sprites and the icon are generated by `python3 generate_graphics.py`. Frame size, frame count and shift there must match `data.lua`.
The entity sprite is the dormant altar. The machine never runs a recipe (crafting machines freeze their animation when idle), so `control.lua` draws the `faustian-fabricator-awake` animation and a light with the rendering API while the machine is powered.

## Power
Power is drawn through the energy source's `drain`, set to the configured kW, because the machine never crafts. Don't try to make it craft: a furnace running a recipe with no results crashes the game when its output inventory is checked, and rejects the generated items.
